# Financial Flow Web

Повноцінний React/Vite клієнт, який повторює основні можливості Android-застосунку.

## Можливості

- дашборд доходів, витрат і загального балансу;
- аналітика за день, тиждень, місяць і рік;
- перемикання та свайпи між сусідніми періодами;
- кільцева діаграма й розподіл сум за категоріями;
- окремий екран створення операції з необов’язковою назвою;
- створення, редагування та видалення категорій;
- адаптивний drawer і світла/темна теми зі збереженням вибору;
- адаптивне компонування для телефона та desktop.

Під час створення операції категорія є обов’язковою, а власна назва — необов’язковою. Без власної назви в списку використовується назва категорії.

## Запуск

```bash
npm install
npm run dev
```

За замовчуванням frontend очікує backend за адресою:

```text
http://localhost:8080/api
```

Можна змінити адресу через `.env`:

```text
VITE_API_URL=http://localhost:8080/api
```

## Docker

Frontend можна підняти разом з backend з кореня проєкту:

```bash
docker compose -f docker-compose.full.yml up --build
```

Після запуску UI буде доступний на:

```text
http://localhost:3000
```
