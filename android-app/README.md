# Financial Flow Android

Мінімальний Android-клієнт для наявного Spring Boot API системи фінансових потоків.

## Можливості

- завантаження списку операцій з `GET /api/transactions`;
- автоматичний підрахунок витрат, доходів і балансу за поточний день, тиждень, місяць або рік;
- кільцева діаграма розподілу грошей за категоріями;
- свайпи між днями, тижнями, місяцями та роками;
- сучасні світла й темна теми з перемикачем у burger-меню;
- монохромний інтерфейс із чіткими контурами та кольоровими даними графіка;
- бокове burger-меню для навігації й майбутніх функцій;
- окремий повноекранний сценарій створення доходу або витрати;
- створення, перегляд, редагування та видалення категорій доходів і витрат;
- обов’язковий вибір категорії під час створення операції;
- необов’язкова власна назва: без неї операція відображається за назвою категорії;
- створення операції через `POST /api/transactions`;
- видалення операції через `DELETE /api/transactions/{id}`;
- стани завантаження та зрозумілі повідомлення про помилки API.

## Технології

- Kotlin;
- Jetpack Compose + Material 3;
- ViewModel, StateFlow і Kotlin Coroutines;
- системний `HttpURLConnection` та `org.json` без додаткової мережевої бібліотеки.

## Запуск

1. Запустіть PostgreSQL і backend з кореня репозиторію:

   ```bash
   docker compose -f docker-compose.backend.yml up --build
   ```

2. Відкрийте папку `android-app` в Android Studio.
3. Запустіть конфігурацію `app` на емуляторі з Android 8.0 або новішим.

Стандартна адреса API для Android Emulator:

```text
http://10.0.2.2:8080/api
```

Для реального пристрою вкажіть IP комп’ютера в локальній мережі:

```bash
./gradlew installDebug -PAPI_BASE_URL=http://192.168.1.10:8080/api
```

Телефон і комп’ютер мають бути в одній мережі, а порт `8080` — доступний для телефона.

## Збірка APK

```bash
./gradlew assembleDebug
```

APK з’явиться в `app/build/outputs/apk/debug/app-debug.apk`.
